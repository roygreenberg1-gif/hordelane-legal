What the invite does

Your friend shared their six-letter code with you. If you enter it before you have won stage 10, you join their game; when you then win stage 10, your friend may get an in-game reward. You get nothing for joining and pay nothing for it, and the game plays the same either way. A code can be entered once, and never your own. Invite friends is on Android now; the iPhone version of the game is coming soon.

The game is free on Google Play, and has optional in-app purchases. An iPhone version is coming soon.

What data is involved

  • This page stores nothing, sets no cookies, counts nothing and sends nothing of its own. On Android it passes the code on to Google Play inside the store link; elsewhere it shows the code to copy. It is hosted on GitHub Pages, which, like any web host, receives the address asked for, code included, and your IP address.
  • On Android, Google Play keeps the code with the install as its install referrer, and the game reads it on the phone the first times you reach the lobby. Only your friend's code is sent from it.
  • In the game, joining adds your BOARD ID, a random identifier of an anonymous account the game creates for you (no name, email or password), to your friend's code's record, and notes which code you joined with; winning stage 10 adds it once more. Anyone who knows the code can read that code's record.
  • On a phone the store reports as under 13, invites do not exist at all.

The details, and how to have these records deleted, are in the Privacy Policy and on Delete your data; the rewards are shown in the game's INVITE & GET window.
