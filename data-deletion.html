Delete your Hordelane data

Hordelane: Zombie Survival — published by Roy Greenberg

Hordelane has no accounts and no sign-in. Nothing it records identifies you: there is no name, no email address, no contact details and no advertising identifier. What it does record is anonymous gameplay information — which stage was played, how it ended, how long it took — tagged with a random DATA ID so that a deletion request can be matched to the right records.

How to request deletion

  1. Open Hordelane on your device.
  2. Tap the AUDIO / settings button in the lobby.
  3. Find the line reading DATA ID, followed by a random 12-character code such as A5514E11EEA5. Tap it — the code is copied to your clipboard and the screen confirms it. The code is yours alone and appears nowhere else.
  4. Paste it into an email to playrg.games@gmail.com with the subject Delete my data.

Nothing else is needed. You do not have to explain why, and there is nothing to prove — the DATA ID is the only thing that connects the records to your copy of the game.

Prefer to stop collection instead of deleting? The same settings screen has a GAME DATA: ON / OFF button. Switching it off stops the game sending anything at all, immediately, and it stays off. You can do both: switch it off and still ask for what was already recorded to be deleted.

What is deleted, and when

DataWhat happens
Gameplay event records tied to your DATA ID
stage numbers, results, duration, upgrades bought		 Deleted. Removed from the analytics reporting console and from the exported analytics tables, within 30 days of the request.
Your DATA ID itself Deleted along with the records it tags. A new random one is generated if you later reinstall.
Your game progress
coins, stages cleared, upgrades, survivors		 Never sent anywhere. It is stored only on your device. Uninstalling the game, or clearing its storage in Android settings, removes it. There is no copy for anyone to delete.
Aggregate counts
e.g. "how many players finished stage 12"		 Retained. These are totals that were never linked to any DATA ID and cannot be traced back to a person.

How long it takes

Requests are handled by one person, so allow a few days for a reply. Deletion is completed within 30 days of the request. You will get an email confirming it is done. Records are kept only for as long as they are useful for improving the game, and are deleted on request in any case.
